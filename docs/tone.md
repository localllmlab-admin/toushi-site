# トーン&マナー定義（デザイン・文体の単一基準）v4

対象読者: 20〜40代の日本人。仕事の合間・帰宅後に、スマホ/PCで投資を体系的に学び直したい層。
サイトの仕事: 「ここは煽らない、本物の学習サイトだ」と3秒で伝え、自分に合う記事へ最短で導く。
経緯: v3「E案（ニュースポータル×求人ポータル）」(2026-07-07) → v4「罫線帳と赤ペン」(2026-10-01 / ADR-0007)。

## デザインコンセプト v4 —「罫線帳と赤ペン」

- 相場の世界の道具＝**方眼の罫線帳**（"罫線"はチャートの和名）に、先生が**赤ペンで添削**を入れる。
  「学び舎」と「相場」を一枚の絵にするのがサイト全体の主題。
- **シグネチャはトップのヒーロー1か所**: 方眼の上にローソク足が立ち、赤ペンで形の名前（ダブルトップ・ネックライン）が書き込まれる。
  ほかの面は静かに保ち、派手さはここだけに使う。
- **構造は事実を表す**: 「学習の時間割」は実際の 7章×4レベルの格子、「最初の3本」は学習マップの実際の並び順。
  番号・格子・数字は実データがあるところにだけ置く（装飾として番号を振らない）。

## 信頼の単位（実績数字を持たない新規サイトの代替）

1. **出典等級**（A=公的機関/B=学術/C=一次発表/D=報道/E=編集部調べ）— 記事冒頭に内訳（A×5 など）、末尾に一覧
2. **7章×4レベルの体系** — トップの「学習の時間割」で常時可視化
3. **更新日・レビュー日** — 記事見出し帯に必ず表示
4. **公開本数の正直な表示** — 帳簿の一行（公開記事・最終更新）。水増し・予定数は出さない
5. バッジは frontmatter の実データからのみ生成する（根拠のない「人気」「おすすめ」表示は作らない）

## タイポグラフィ

- **見出し = しっぽり明朝B1（800）**: 教科書の声。h1・h2・セクション見出し・ブランド名のみ。
  Google Fonts を `display=optional` で読む＝間に合わなければOS明朝のまま描画し、CLSを出さない。
- **本文 = OS搭載ゴシック**: 記事本文16.5px相当・行間2.0（スマホ16px・1.95）。16px未満にしない。
- **データ = IBM Plex Mono**: 日付・本数・出典等級・目次番号に限定。本文に使わない。
- 日本語ラベルの字間は最大 .1em。英字の大文字ラベルを日本語に流用しない。
- 強調（strong）は太字＋赤ペンの傍線（下35%の淡い朱）。色だけに頼らない。

## 文体（既存リンター・コンプラ0章と整合）

- 本文は敬体。キャッチコピーのみ常体・体言止め可（例:「相場を、正しく学ぶ。」）。
- 断定禁止・最上級表現禁止（「必ず」「絶対」「No.1」）。条件付き推奨のみ。
- 模式図には必ず「模式図（実在の銘柄・相場ではありません）」を添える。赤ペンの書き込みは**形の名前**のみで、売買の指示は書かない。
- ボタンは押すと何が起きるかを書く（「入門の1本目から読む」「時間割を見る」）。

## 品質床（出荷条件）

- Lighthouse Performance 90以上・CLS 0.1以下・SEO 100・a11y 100
- 390px幅で横スクロールなし。タップ領域44px以上
- ナビは全項目を常時表示（スマホは4列×2段の格子）。隠さない
- キーボードフォーカス可視・スキップリンク・prefers-reduced-motion で動きを止める
- JSアイランドは最小限（検索ページ・/learn/ の lv フィルタのみ）。演出は CSS（ローソク足の登場・赤ペン・読書進捗バー）で行う
