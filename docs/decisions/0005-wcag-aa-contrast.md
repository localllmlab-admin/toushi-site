# ADR-0005: 補助テキストとリンク色を WCAG 2.1 AA（4.5:1）準拠に引き上げる

- 日付: 2026-08-04
- ステータス: 承認（Masaru承認 2026-08-04）

## 背景

SEO強化の一環として Lighthouse を実測したところ、performance / best-practices / SEO は
全ページ 97〜100 だったのに対し、accessibility だけが 95〜97 で止まっていた。
落ちていた監査項目は `color-contrast` の1つだけで、指摘対象は延べ28要素あったが、
原因は tokens.css の色定義4つに集約されていた。

実測したコントラスト比（WCAG 2.1 AA の基準は通常テキストで 4.5:1）:

| トークン / 直書き | 色 | 地 | 比 | 判定 |
|---|---|---|---|---|
| `--color-text-muted` | `#71809a` | `#ffffff` | 3.99 | ✗ |
| `--color-text-muted` | `#71809a` | `#f7fafd`（surface） | 3.81 | ✗ |
| `--color-text-muted` | `#71809a` | `#e9eef5`（surface-muted） | 3.43 | ✗ |
| `--color-on-ink-muted` | `#9dbbd4` | `#004f86`（ink） | 4.26 | ✗ |
| `.foot-copy` 直書き | `#7fa6c6` | `#004f86` | 3.32 | ✗ |
| `--color-accent` | `#0075c2` | `#f2f5f9`（page） | 4.44 | ✗ |
| `--color-accent` | `#0075c2` | `#e8f3fb` | 4.31 | ✗ |
| `.b-new` 直書き | `#e5322d` | `#ffffff` | 4.35 | ✗ |

影響範囲は装飾ではなく可読性そのもの（記事の最終更新日、図のキャプション、
出典の等級バッジ、免責事項、フッター全文、本文中リンク）で、全ページに及ぶ。

## 選択肢

1. **色を変えず文字サイズを上げる** — WCAG は 18pt 以上（または14pt太字）なら 3:1 で足りる。
   ただし対象は「補助情報」であり、本文より小さいこと自体が情報設計の一部。
   大きくすると主従が崩れ、E案の情報密度が損なわれる。
2. **色をAA準拠まで調整する** — 色相はそのままに明度だけ動かす。
   トーンは維持され、変更は tokens.css の3行と直書き2箇所で完結する。
3. **見送る** — Lighthouse のスコアは下がるが検索順位への直接影響はない。

## 決定

案2を採る。色相を保ったまま明度のみを調整し、その色が実際に載る**すべての地**に対して
4.5:1 以上を満たす値にする。

| トークン | 旧 | 新 | 新しい実測比（最も不利な地） |
|---|---|---|---|
| `--color-text-muted` | `#71809a` | `#5b6980` | 4.77（`#e9eef5` 上） |
| `--color-on-ink-muted` | `#9dbbd4` | `#a8c6dd` | 4.79（`#004f86` 上） |
| `--color-accent` | `#0075c2` | `#006db5` | 4.67（`#e9eef5` 上） |
| `.foot-copy`（直書き） | `#7fa6c6` | `var(--color-on-ink-muted)` | 4.79 |
| `.b-new`（直書き） | `#e5322d` | `#d42722` | 5.11（白地） |

`--color-ink-2`（`#0075c2`）は**変更しない**。ブランド青のグラデーション
（`--grad-brand`）の中間色であり、文字色ではなく装飾面だからである。
つまり「ブランド青そのもの」は保たれ、変わるのは**テキストに使う青**だけ。

## 根拠

- 基準は WCAG 2.1 達成基準 1.4.3（コントラスト・最低限）＝通常テキスト 4.5:1。
  https://waic.jp/translations/WCAG21/#contrast-minimum （確認日: 2026-08-04）
- 「AA未達である」ことは推測ではなく Lighthouse 13.4.1 の実測値。上表の比は
  相対輝度式（WCAG 定義）で再計算して照合済み。
- 閾値の当て方は [[feedback-calibrate-targets-from-real-data]] の教訓に従い、
  「白地で4.5を超えればよい」ではなく**実際に載る地すべて**で測った。
  白地だけで判定すると `#5f6d85`（白地5.23）でも `#e9eef5` 上では4.49で落ちる。
- 姉妹サイト「AIのいろは」でも同種の判断を先行採用している（ADR-0003 相当）。

## 影響

- **見た目**: 補助テキストがわずかに濃く、リンクの青がわずかに深くなる。
  レイアウト・字送り・要素サイズは一切変わらない（CLS 0 を実測で維持）。
- **検証**: Lighthouse accessibility が全実測ページで 100 になった
  （top / learn 一覧 / books 一覧 / 記事 / 用語集の5ページ・実測 2026-08-04）。
- **単一基準の維持**: `tokens.css` が引き続き色の唯一の定義元。今回、フッターの
  `.foot-copy` に残っていた直書きをトークン参照へ寄せたので、逸脱は
  `#1a68a5`（フッター罫線）と `#e8f3fb`（hover地）のみになった。
- **回帰リスク**: Lighthouse はCIに入っていないため、色を触ると再び落ちうる。
  当面は UI 変更時に手動で Lighthouse を実測する運用を継続する
  （[[feedback-lighthouse-verify-dont-assume]]）。
- `design/samples/e-portal-blue.html` は**比較検討時の記録**なので旧色のまま残す
  （正はあくまで tokens.css + docs/tone.md）。
